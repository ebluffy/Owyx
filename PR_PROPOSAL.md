**Ветка:** `feat/design-de-slop`

---

## 📌 О чём этот PR

Привет, ebluffy! 👋  
Лаунчер Owyx выглядит круто, но сайт (`owyxsite/frontend`) в последних коммитах начал отдавать типичными артефактами «нейрослопа» (шаблонов, которые генерируют AI-боты): сломанные шрифты на русском языке, плоские кнопки с ядовитой размытой тенью, паутина из соединяющихся линий на канвасе и пустая дыра в первом экране.

Этот PR точечно и бережно доводит UI сайта до уровня **настоящего премиального десктопного продукта**, сохраняя все правила из [`brand/DESIGN.md`](./brand/DESIGN.md) (базовый фон `#050508`, акцент `#00e5ff`, отсутствие золота Minecraft, паритет роутов и локалей).

---

## 🔍 Какие проблемы были устранены

### 1. 🔤 «Тупые шрифты» (Критический баг с кириллицей)
* **Проблема:** В `layout.tsx` шрифты Google Fonts (`Sora`, `Outfit`, `DM_Sans`) были подключены с подмножеством `subsets: ["latin", "latin-ext"]`.  
  Поскольку сайт по умолчанию на русском языке (`lang="ru"`), а в скачанных файлах не было кириллических глифов, **весь русский текст на сайте принудительно рендерился в дефолтных системных шрифтах Windows/Mac (Arial / Segoe UI)**. В итоге сайт выглядел как сломанный AI-шаблон.
* **Решение:** Подключен современный типографический стек со 100% поддержкой **Cyrillic + Latin**:
  - **`Onest`** (`--font-onest`): экранный гротеск с идеальным кернингом и нативной кириллицей для UI и основного текста.
  - **`Unbounded`** (`--font-unbounded`): футуристичный технологичный геометрический шрифт для акцентных заголовков.
  - **`JetBrains Mono`** (`--font-jetbrains-mono`): эталонный моноширинный шрифт для IP, версий и чисел.
  - **`Sora`**: сохранена для латинского слова `owyx™`.

### 2. 🎛️ «Дешёвые кнопки» (Тактильный High-Craft дизайн)
* **Проблема:** Кнопки были плоскими прямоугольниками одного цвета с размытым пятном `box-shadow: 0 6px 20px -8px rgba(0, 229, 255, 0.5)`. Без фаски, без градиента, без отклика на нажатие — классический «бутстрап 2021».
* **Решение:**
  - **Primary (`.btn-primary`)**:
    - Глубокий градиент `linear-gradient(180deg, #1ce8ff 0%, #00d2ec 100%)`.
    - Спекулярная фаска по верхней кромке (`box-shadow: inset 0 1px 0 rgba(255,255,255,0.65)`).
    - Тактильный отклик: физическое нажатие `:active` (`scale(0.985) translateY(1px)`) с компрессией тени.
  - **Secondary / Ghost (`.btn-secondary`, `.btn-ghost`)**:
    - Тёмное матовое стекло `rgba(255, 255, 255, 0.035)` с `backdrop-filter: blur(8px)`.
    - Тонкая световая граница `rgba(255, 255, 255, 0.09)`.
    - Плавное акцентное подсвечивание на `:hover` без резких скачков.

### 3. 🕸️ Де-слопинг фона (Удаление спайдервеб-паутины)
* **Проблема:** В `SpaceParticles.tsx` точки соединялись линиями при сближении (`ctx.lineTo()` в цикле $O(N^2)$). Это избитый шаблон из 2018 года, который сейчас генерирует каждый второй AI-генератор. Кроме того, он создавал лишнюю нагрузку на CPU/батарею на слабых ноутбуках.
* **Решение:**
  - Паутина удалена.
  - Реализовано органичное 3D-пространство глубокого космоса:
    - 3 слоя глубины: далёкие мерцающие микрозвёзды (Layer 1), космическая циановая пыль (Layer 2) и редкие парящие кристаллические частицы с мягким радиальным свечением (Layer 3).
    - Сложность $O(N)$, шелковистые 60 FPS, нулевая перегрузка процессора.

### 4. 🚀 Первый экран (Hero) и статус сервера
* **Проблема:** На десктопе правая половина экрана была гигантской черной пустотой (`max-w-2xl` на 6xl-контейнере). Кроме того, в коде отсутствовал блок **«Статус сервера + IP (копирование)»**, хотя в `brand/DESIGN.md` §5 item 3 он прямо указан как обязательный элемент первого экрана.
* **Решение:**
  - Внедрён компактный серверный статус-пилл прямо в Hero: живая точка онлайна, адрес `mc.owyx.site` и кнопка копирования в один клик с анимированным статусом «Скопировано!».
  - На десктопе справа добавлен стильный **Launcher Preview Widget** (окно лаунчера Owyx v0.5.2 в титановой рамке с карточкой быстрого входа Offline / Microsoft OAuth и кнопкой быстрого запуска Play ▶). Пользователь с первой секунды понимает, что зашел на сайт лаунчера, а не на пустой лендинг.
  - Версионный бейдж заменен на аккуратный статус-чип: `[ • Публичная Beta / v0.5.2 ]`.

### 5. 📰 Новости и CTA-карточка
* Список новостей переведён с плоских линий на аккуратные карточки-строки с мягким hover-хайлайтом, моноширинными датами и тегами.
* Финальный CTA-блок получил радиальную световую подложку и тактильные кнопки.

## 📊 Таблица сравнения: До и После

| Элемент | До редизайна | После редизайна (Этот PR) |
| :--- | :--- | :--- |
| **Русские шрифты** | Системный fallback (Arial / Segoe UI) из-за latin-only Google Fonts | Премиальные `Onest` (UI) + `Unbounded` (заголовки) с нативной кириллицей |
| **Кнопки** | Плоский `#00e5ff`, размытая тень, без фаски и физики клика | Трёхслойный тактильный градиент, спекулярная фаска, физический `:active scale(0.985)` |
| **Canvas частицы** | AI-паутина из соединяющихся линий ($O(N^2)$) | Кинематографичная космическая звёздная пыль с 3 уровнями глубины ($O(N)$) |
| **Hero (первый экран)** | Пустая правая часть, отсутствует блок IP/онлайна | Виджет лаунчера справа + компактный серверный статус-пилл с копированием IP |
| **Новости** | Сухие разделительные полосы | Карточки с hover-состоянием, моно-датами и чистыми тегами |

## 🛠️ Как проверить локально

```bash
# 1. Переключиться на ветку с редизайном
git checkout feat/design-de-slop

# 2. Перейти в директорию фронтенда
cd owyxsite/frontend

# 3. Установить зависимости и запустить
npm install   # или pnpm install
npm run dev
```

Откройте `http://localhost:3000` в браузере:
1. Обратите внимание на начертание русских букв в заголовках и текстах (четкие геометрические формы, никакого Segoe UI).
2. Наведите мышь на кнопки и нажмите их (оцените спекулярный блик и физику нажатия).
3. Проверьте копирование IP в Hero-блоке (кликните на `mc.owyx.site`).
4. Посмотрите на фон (плавные частицы без раздражающих связующих нитей).
